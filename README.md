# Pixiv 小说与作品下载器

一个单文件 Tampermonkey/油猴脚本：提取当前可访问的 Pixiv 小说，并下载插画或漫画作品的原图。小说内容只在浏览器本地处理。

## 安装

1. 在浏览器中安装 Tampermonkey。
2. 打开 Tampermonkey 管理面板，新建脚本。
3. 将 [`pixiv-novel-extractor.user.js`](pixiv-novel-extractor.user.js) 这一文件的完整内容粘贴进去并保存。
4. 打开 Pixiv 小说详情页或作品页（例如 `https://www.pixiv.net/novel/show.php?id=123456` 或 `https://www.pixiv.net/artworks/123456`）。

脚本会在页面右下角显示面板，也会注册相应的油猴菜单命令。脚本通过元数据加载固定版本 `jszip@3.10.1`，用于生成多图 ZIP。

## 功能

- 复制当前小说
- 下载当前小说
- 下载整个系列
- 在作品页点击“下载当前作品”下载原图

面板右上角的最小化按钮可将面板缩成右下角的圆形图标；再次点击图标即可恢复。脚本会记住最小化状态，刷新页面或打开另一篇 Pixiv 小说后仍保持原状态。

单篇文本使用“作品标题 + 正文”格式。系列文本按 Pixiv 系列顺序合并，并为每篇加入章节分隔。注音会转换为 `汉字（读音）`；章节、分页、页内跳转和插图标记会转换成可阅读的纯文本提示。

系列章节按顺序逐篇请求，相邻请求之间有短暂间隔。个别作品删除或无权访问时，脚本会写入失败占位并继续处理后续作品。

### 插画和漫画作品

- 单图作品直接下载一张 JPG/PNG（保留 Pixiv 原图扩展名）。
- 多图作品按 Pixiv 顺序下载原图并打包为 ZIP，文件名使用三位数页码。
- 每张图片最多自动重试一次。多图下载失败率严格超过 20% 时立即停止；恰好 20% 时继续生成 ZIP。
- 仍有失败页时，ZIP 内会包含 `下载失败.txt`，记录页码、原图地址和错误信息。
- 动图（ugoira）暂不支持。
- 大型作品会在浏览器内下载并生成 ZIP，可能占用较多内存；请确保浏览器有足够可用内存。

## 限制与隐私

- 脚本只处理当前浏览器账号原本有权访问的内容，不绕过登录、年龄分级、作者可见性或区域限制。
- DOM 兜底仅适用于当前已渲染的单篇小说；获取系列列表失败时不会猜测章节。
- 图片请求只针对 Pixiv 原图主机 `i.pximg.net`；不绕过访问控制。
- 小说内容只在浏览器本地处理，不发送到 Pixiv 以外的服务。
- 作品页和小说页都遵守你当前账号已有的登录、年龄分级、作者可见性和区域限制；脚本不会绕过这些访问控制。
- Pixiv 的站内数据结构并非公开稳定 API；如网站改版，可能需要更新脚本。

## 开发验证

需要 Node.js 20 或更高版本：

```powershell
npm test
node --check pixiv-novel-extractor.user.js
```

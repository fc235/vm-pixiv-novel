# Pixiv 小说提取器

一个单文件 Tampermonkey/油猴脚本，用于提取当前可访问的 Pixiv 小说标题和正文，并复制到剪贴板或下载为 UTF-8 纯文本。

## 安装

1. 在浏览器中安装 Tampermonkey。
2. 打开 Tampermonkey 管理面板，新建脚本。
3. 将 [`pixiv-novel-extractor.user.js`](pixiv-novel-extractor.user.js) 的完整内容粘贴进去并保存。
4. 打开形如 `https://www.pixiv.net/novel/show.php?id=123456` 的小说详情页。

脚本会在页面右下角显示“Pixiv 小说提取”面板，也会注册相同的油猴菜单命令。

## 功能

- 复制当前小说
- 下载当前小说
- 复制整个系列
- 下载整个系列

单篇文本使用“作品标题 + 正文”格式。系列文本按 Pixiv 系列顺序合并，并为每篇加入章节分隔。注音会转换为 `汉字（读音）`；章节、分页、页内跳转和插图标记会转换成可阅读的纯文本提示。

系列章节按顺序逐篇请求，相邻请求之间有短暂间隔。个别作品删除或无权访问时，脚本会写入失败占位并继续处理后续作品。

## 限制与隐私

- 脚本只处理当前浏览器账号原本有权访问的内容，不绕过登录、年龄分级、作者可见性或区域限制。
- DOM 兜底仅适用于当前已渲染的单篇小说；获取系列列表失败时不会猜测章节。
- 插图只保留 Pixiv 作品 ID 提示，不下载图片。
- 小说内容只在浏览器本地处理，不发送到 Pixiv 以外的服务。
- Pixiv 的站内数据结构并非公开稳定 API；如网站改版，可能需要更新脚本。

## 开发验证

需要 Node.js 20 或更高版本：

```powershell
npm test
node --check pixiv-novel-extractor.user.js
```

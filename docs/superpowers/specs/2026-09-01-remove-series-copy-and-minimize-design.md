# 移除系列复制与完善最小化设计

## 目标

精简 Pixiv 小说提取器的操作入口，移除使用价值较低的“复制整个系列”，同时把当前仅隐藏内容区的折叠行为改为真正的最小化：面板缩为右下角圆形按钮，并在刷新或打开其他小说页面后保持用户选择的状态。

## 功能变更

完整面板只保留三项操作：

- 复制当前小说
- 下载当前小说
- 下载整个系列

删除“复制整个系列”的面板按钮、油猴菜单命令、控制器入口和对应测试。系列数据提取与文本组装能力继续保留，因为“下载整个系列”仍需要它。

## 最小化交互

- 完整面板继续显示标题、三个操作按钮、状态区域和最小化按钮。
- 点击最小化按钮后，同一面板进入紧凑状态，缩为固定在页面右下角、约 44 像素的圆形启动按钮。
- 紧凑状态隐藏标题、操作按钮和状态文字，只显示清晰的小说/文档图标。
- 点击圆形按钮恢复完整面板。
- 两种状态均提供准确的 `title`、`aria-label` 和 `aria-expanded` 信息，并可通过键盘聚焦及激活。
- 状态切换只使用同一个 DOM 容器和 CSS 状态类，不重建面板或重复绑定事件。

## 状态持久化

使用油猴的 `GM_getValue` 和 `GM_setValue` 保存最小化状态。脚本启动时读取该值：

- 保存值为 `true` 时直接以圆形按钮显示。
- 没有保存值或读取失败时默认显示完整面板。
- 用户每次切换状态后立即保存；保存失败不影响当前页面内的切换。

脚本元数据增加对应的 `@grant` 声明。存储仅包含一个布尔界面偏好，不包含小说内容或账号信息。

## 兼容与错误处理

- 不改变当前小说复制的无回调剪贴板实现，避免重新引入复制卡住问题。
- 不改变单篇和系列下载、进度显示、访问权限检查及请求节制逻辑。
- 若油猴存储 API 不可用，最小化仍在当前页面正常工作，只是不跨页面保留。
- 非系列作品继续禁用“下载整个系列”，并显示现有原因说明。

## 文档与版本

- 更新脚本版本号和功能描述。
- README 功能列表移除“复制整个系列”，并说明最小化按钮及状态记忆行为。
- 不删除仍被系列下载使用的公共格式化和提取函数。

## 验收标准

1. 面板与油猴菜单中都不再出现“复制整个系列”。
2. 当前小说复制、当前小说下载和整个系列下载继续正常工作。
3. 点击最小化后，完整面板缩为右下角约 44 像素的圆形按钮，没有残留标题、状态或空白区域。
4. 点击圆形按钮可恢复完整面板，且不会重复创建按钮或重复触发操作。
5. 最小化状态在刷新页面及打开另一篇 Pixiv 小说后保持。
6. 存储接口异常时，当前页面的展开/最小化切换仍可使用。
7. 自动化测试覆盖操作入口移除、最小化切换、状态恢复和存储失败场景；脚本语法检查通过。

## 验证策略

- 调整控制器和启动测试，确认不再注册系列复制操作及菜单。
- 使用模拟 DOM 验证完整和紧凑状态的类名、可见内容及无障碍属性。
- 使用模拟 `GM_getValue` / `GM_setValue` 验证初始恢复、切换保存和异常降级。
- 运行全部 Node 测试和 `node --check pixiv-novel-extractor.user.js`。
- 在 Tampermonkey 中手动刷新页面并打开另一篇小说，确认圆形按钮状态能够保持且三个剩余功能可用。
